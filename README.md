# SBT-Smart_Barbell_Tracker
Hi, this is my first bigger free time project. To by honest its mainly created by Gemini3.1 Pro. The project itself is about creating smart tracker for powerlifting in form of profesional gym gear. The hardware is based on ESC32-C6 mikrocontroller with MPU6500 sensor. The software consists of aplication based on Python and src of ESC32 on C++.
